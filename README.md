# Cristal CRM - Sistema de Gestión Comercial

Sistema CRM completo para Cristal Desarrollos Inmobiliarios - Buenos Aires

## 🚀 Características

- ✅ Gestión de ventas con comisiones automáticas
- ✅ Pipeline de leads con drag & drop
- ✅ Registro de gastos con análisis IA
- ✅ Documentación (Hojas de visita en PDF)
- ✅ Panel administrativo completo
- ✅ Sistema multi-usuario (Admin + Vendedores)
- ✅ Responsive design (Desktop + Mobile)

## 🔧 Deploy en Vercel

1. Importá este repositorio en Vercel
2. Vercel detecta automáticamente Vite
3. Deploy automático
